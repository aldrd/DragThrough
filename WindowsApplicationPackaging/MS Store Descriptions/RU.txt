# Description
Перетаскивайте файлы в любое окно — даже в то, которое скрыто за Проводником.
Ситуация знакомая: вы взяли один файл или несколько в Проводнике, а окно, куда их нужно бросить, находится прямо за ним и полностью закрыто. Приходится отменять перетаскивание, сворачивать Проводник, искать окно, возвращаться и начинать заново.
DragThrough убирает этот шаг. Удерживайте Shift (или клавишу Windows) при перетаскивании файлов в Проводнике — и Проводник временно уходит с пути, позволяя бросить файлы прямо в окно, которое было за ним. Одно перетаскивание, и готово.
Кроме того, приложение добавляет необязательную дополнительную панель задач с плавными перетаскиваемыми кнопками, которая учитывает, на каком виртуальном рабочем столе вы находитесь.

# New in this version
Небольшие улучшения.

# Product features
Удерживайте Shift или клавишу Windows при перетаскивании в Проводнике, чтобы бросить файлы в окно за ним
Автоматически сворачивать Проводник после успешного перетаскивания
Необязательная тонкая дополнительная панель задач с перетаскиваемыми кнопками задач
Меняйте порядок кнопок перетаскиванием, как вкладки в Chrome
Для каждого виртуального рабочего стола: показываются только окна текущего стола
Работает незаметно из области уведомлений

# Short description
Перетаскивайте файлы в любое окно — даже в то, которое скрыто за Проводником. Удерживайте Shift при перетаскивании, и Проводник уйдёт с пути, позволяя бросить файлы прямо в окно за ним. Включает необязательную дополнительную панель задач с перетаскиваемыми кнопками задач, которая учитывает виртуальные рабочие столы.
