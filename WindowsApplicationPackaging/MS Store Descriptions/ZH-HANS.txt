# Description
将文件拖放到任何窗口 —— 即使它被文件资源管理器挡住。
这个场景你一定熟悉：你在文件资源管理器中选中了一个或几个文件，但要拖放到的那个窗口就在它后面，被完全遮住。于是你只能取消拖动、最小化资源管理器、找到窗口、再回来重新开始。
DragThrough 省去了这一步。在资源管理器中拖动文件时按住 Shift（或 Windows 键），资源管理器会临时让开，你就能直接拖放到原本被遮住的窗口上。一次拖动即可完成。
它还提供一个可选的辅助任务栏，任务按钮可平滑拖动，并且能识别你当前所在的虚拟桌面。

# Product features
在文件资源管理器中拖动时按住 Shift 或 Windows 键，即可拖放到后面的窗口上
成功拖放后自动最小化文件资源管理器
可选的纤薄辅助任务栏，任务按钮可拖动
像 Chrome 标签页一样拖动调整任务按钮的顺序
按虚拟桌面区分：仅显示当前桌面上的窗口
安静地运行于系统托盘

# Short description
将文件拖放到任何窗口 —— 即使它被文件资源管理器挡住。拖动时按住 Shift，资源管理器便会让开，让你直接拖放到后面的窗口上。另含一个可选的辅助任务栏，任务按钮可拖动，并能识别虚拟桌面。
