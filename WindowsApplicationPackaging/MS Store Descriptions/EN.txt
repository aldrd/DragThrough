# Description
Drag files onto any window — even the ones hidden behind File Explorer.
You know the dance: you grab one or a few files in File Explorer, but the window you want to drop them on is right behind it — completely covered. So you cancel the drag, minimize Explorer, find the window, go back, and start over.
DragThrough removes that step. Hold Shift (or the Windows key) while dragging files in Explorer, and Explorer temporarily slides out of the way — so you can drop straight onto the window that was behind it. One drag, done.
It also adds an optional secondary taskbar with smooth, draggable task buttons that knows which virtual desktop you're on.

# New in this version
Small improvements.

# Product features
Hold Shift or the Windows key while dragging in File Explorer to drop onto the window behind it
Auto-minimize File Explorer after a successful drop
Optional slim secondary taskbar with draggable task buttons
Reorder task buttons by dragging, Chrome-tab style
Per–virtual-desktop: shows only the current desktop's windows
Runs quietly from the system tray

# Short description
Drag files onto any window — even the ones hidden behind File Explorer. Hold Shift while dragging and Explorer slides out of the way, so you can drop straight onto the window behind it. Includes an optional secondary taskbar with draggable task buttons that's aware of your virtual desktops.
